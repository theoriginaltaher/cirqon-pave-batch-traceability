How it works

One scan. A clearer material story.

Each code opens a simple batch record designed to make the sample inputs and estimates easy to understand.

  1. 1

    Every batch gets a QR code

    A unique code connects the paving tiles to one sample batch record.

  2. 2

    Scan it on the tile

    Use a phone camera to open the mobile-first batch page.

  3. 3

    See recycled content and impact

    Review sample material quantities and a clearly labelled CO2 estimate.
